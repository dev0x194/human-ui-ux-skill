# Ready-to-use prompts for Codex

Copy one relevant prompt. The `$human-ui-ux` name explicitly invokes the skill.

## Expo Android + iOS

> Use $human-ui-ux to improve my existing Expo Router app for Android and iOS. Read the Expo reference. Keep my existing routing and dependencies. Design a distinctive, task-first mobile interface with accessible tap targets, safe areas, correct back behavior, empty/error/loading states and an intentional typographic style. Test what the environment allows and state which devices were not tested.

## Expo Android + iOS + web

> Use $human-ui-ux to build a universal Expo Router experience for Android, iOS and web. Reuse React Native components where compatible and split .web/.native files only when necessary. Ensure layouts adapt to phone, tablet and desktop browser widths. Define a human-directed design language, functional interactions and accessible behavior. Do not claim native desktop app support.

## React / Vite / Next web

> Use $human-ui-ux to design a responsive, editorial, product-specific web interface in my existing React app. Inspect the current framework, maintain route conventions, define a token system, and implement real interactions. Avoid default purple-blue gradients, cookie-cutter cards, generic AI hero copy and nonfunctional buttons. Verify mobile and desktop layouts when browser tools are available.

## Vanilla HTML/CSS/JavaScript

> Use $human-ui-ux to build an accessible, high-quality landing page with HTML, CSS and JavaScript only. Lead with an original content hierarchy and precise product copy, not a generic SaaS template. Use CSS tokens, responsive composition and working UI interactions. No framework or heavy dependency.

## Desktop Electron/Tauri

> Use $human-ui-ux to craft a focused, keyboard-first desktop app UI in my existing Electron or Tauri project. Check its security/native integration architecture first. Design intentional dense information, resizable-window behavior, keyboard navigation and native-feeling controls. Preserve the framework's IPC and permission conventions. Test only on environments actually available.

## Cross-platform design plan

> Use $human-ui-ux to propose and implement a feasible UI architecture for Android, iOS, web and desktop. First classify which surfaces can share code (Expo native/web vs desktop web shell), then create shared design tokens and platform-specific navigation/interaction standards. Avoid pretending a single Expo build creates a Windows/macOS app. Prioritize working task flow, performance and accessibility over generic AI styling.
